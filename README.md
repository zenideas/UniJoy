## 🧠 স্মার্ট ব্যবহার বিধি (Smart Usage Guidelines)

### ১. ডাবল দাঁড়ি (`॥`) বনাম পাইপ চিহ্ন (`|`)
* **কখন `॥` (Option + `\`) ব্যবহার করবেন:** 
  বাংলা সাহিত্য, কবিতা, নাটক বা ধর্মীয় বইয়ের শ্লোক রচনার ক্ষেত্রে যেখানে প্রাতিষ্ঠানিক ডাবল দাঁড়ি প্রয়োজন হয়।
* **কখন `|` (Shift + Option + `\`) ব্যবহার করবেন:** 
  আপনি যখন উইকিপিডিয়া সম্পাদনা, মার্কডাউন ফরম্যাটিং (যেমন: `| কলাম ১ | কলাম ২ |`), প্রোগ্রামিং কোড বা টার্মিনালে কাজ করবেন, তখন এই পাইপ সিম্বলটি ব্যবহার করুন। বাংলা লেআউট থেকে বের না হয়েই টেকনিক্যাল কাজ সম্পন্ন করার জন্য এটি অত্যন্ত কার্যকর।

---

### ২. টাইপিং অভ্যাসের সুবিধা: স্মার্ট কোটেশন (`“”`)
ডাবল কোটেশনের ক্ষেত্রে দুটি আলাদা শর্টকাট সেট রাখা হয়েছে যাতে ব্যবহারকারীর টাইপিং অভ্যাসে কোনো ব্যাঘাত না ঘটে:
1. **ম্যাক সিস্টেম অভ্যাস (`Option + 9` এবং `Option + 0`):** ম্যাকওএস ডিফল্ট শর্টকাটে যারা অভ্যস্ত, তারা খুব সহজেই ব্র্যাকেটের উপরের ৯ ও ০ কী দিয়ে এটি টাইপ করতে পারবেন।
2. **ভিজ্যুয়াল অভ্যাস (`Shift + Option + <` এবং `Shift + Option + >`):** তীরের দিক দেখে যারা বাঁকা কোটেশন বুঝতে পছন্দ করেন, তারা `<` ও `>` সমন্বিত কি-গুলো ব্যবহার করতে পারবেন।

---

### ৩. টাইপোগ্রাফিক ও আর্থিক চিহ্নের সঠিক নিয়ম
* **টাকা চিহ্ন (`৳`):** এটি `Option + 4` দিয়ে টাইপ করা যায় (কারণ `Shift + 4` দিয়ে ইংরেজি `$` আসে)।
* **এম-ড্যাশ (`—`):** সাধারণ হাইফেন (`-`) এর বদলে জটিল বা দীর্ঘ ব্যাখ্যাযুক্ত বাক্যে `Shift + Option + -` চাপলে একটি নিখুঁত এম-ড্যাশ তৈরি হবে।
