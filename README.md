# ⌨️ macOS বাংলা ইউনিজয় কীবোর্ড লেআউট: সর্বাঙ্গীন নির্দেশিকা ও সিম্বল গাইড

এই ডকুমেন্টেশনে আপনার ম্যাকের `UniJoy.keylayout` ফাইলে থাকা সমস্ত ব্যঞ্জনবর্ণ, স্বরবর্ণ, কারচিহ্ন, ঐতিহাসিক ও বৈদিক প্রতীক, মুদ্রা, গাণিতিক চিহ্ন এবং অদৃশ্য ফরম্যাটিং ক্যারেক্টারগুলোর পূর্ণাঙ্গ তালিকা ও ব্যবহারের নিয়ম তুলে ধরা হলো।

ইউনিজয় লেআউটের মূল বৈশিষ্ট্য হলো নির্দিষ্ট কারচিহ্নের ওপর হসন্ত বা বিশেষ প্রেসের মাধ্যমে স্বাধীন স্বরবর্ণ তৈরি করা:

## 📌 বিশেষ বিরামচিহ্ন ও সিম্বল গাইড (Quick Reference)

| চিহ্ন | বিবরণ / নাম | কীবোর্ড শর্টকাট (Mac) | ব্যবহারের ক্ষেত্র / উদাহরণ |
| :---: | :--- | :--- | :--- |
| **`॥`** | ডাবল দাঁড়ি (Double Danda) | `Option + \` | কাব্য গ্রন্থ, ধর্মীয় শ্লোক বা প্রাচীন সাহিত্য |
| **`\|`** | আসকি পাইপ (ASCII Pipe) | `Shift + Option + \` | মার্কডাউন টেবিল, কোডিং, রেগুলার এক্সপ্রেশন, কমান্ড লাইন |
| **`ঽ`** | অবগ্রহ (Avagraha) | `Option + K` | সংস্কৃত ও প্রাচীন ছন্দে অ-কার লোপ বোঝাতে | 
| **`৾` ** | সন্ধি চিহ্ন (Sandhi Mark) | `Shift + Option + -` | ব্যাকরণে সন্ধির সংযোগ প্রকাশে | 
| **`ঀ`** | বৈদিক প্রতীক / আনজি | `Option + J` | বৈদিক বা মাঙ্গলিক লিপি চিহ্ন | 
| **`৽`** | বাংলা সংক্ষেপণ চিহ্ন | `Shift + Option + ?` | প্রাতিষ্ঠানিক বা প্রাচীন সংক্ষেপণে | 
| **`ৼ`** | বৈদিক অনুস্বার | `Shift + Option + R` | বৈদিক স্বরগ্রামের বিশেষ রূপ | 
| **`॑`** | উদাত্ত স্বরচিহ্ন (Udatta) | `Option + X` | বৈদিক মন্ত্রের উঁচু স্বর | 
| **`॒`** | অনুদাত্ত স্বরচিহ্ন (Anudatta) | `Option + Z` | বৈদিক মন্ত্রের নিচু স্বর | 
| **`“`** | লেফট ডাবল কোটেশন | `Option + 9` **বা** `Shift + Option + <` | উইকি বা বাংলা উদ্ধৃতি শুরু করতে |
| **`”`** | রাইট ডাবল কোটেশন | `Option + 0` **বা** `Shift + Option + >` | বাংলা উদ্ধৃতি শেষ করতে |
| **`‘`** | লেফট সিঙ্গেল কোটেশন | `Option + ]` | একক উদ্ধৃতি শুরু |
| **`’`** | রাইট সিঙ্গেল কোটেশন | `Option + [` | একক উদ্ধৃতি শেষ বা লোফ চিহ্ন |
| **`—`** | এম-ড্যাশ (Em-Dash) | `Shift + Option + -` | বাক্যে বিরতি বা ব্যাখ্যা যুক্ত করতে |
| **`•`** | বুলেট পয়েন্ট (Bullet) | `Option + 8` | তালিকা বা নোট তৈরি করতে |

## 🧠 স্মার্ট ব্যবহার বিধি (Smart Usage Guidelines)

### ১. ডাবল দাঁড়ি (`॥`) বনাম পাইপ চিহ্ন (`|`)
* **কখন `॥` (Option + `\`) ব্যবহার করবেন:** 
  বাংলা সাহিত্য, কবিতা, নাটক বা ধর্মীয় বইয়ের শ্লোক রচনার ক্ষেত্রে যেখানে প্রাতিষ্ঠানিক ডাবল দাঁড়ি প্রয়োজন হয়।
* **কখন `|` (Shift + Option + `\`) ব্যবহার করবেন:** 
  আপনি যখন উইকিপিডিয়া সম্পাদনা, মার্কডাউন ফরম্যাটিং (যেমন: `| কলাম ১ | কলাম ২ |`), প্রোগ্রামিং কোড বা টার্মিনালে কাজ করবেন, তখন এই পাইপ সিম্বলটি ব্যবহার করুন। বাংলা লেআউট থেকে বের না হয়েই টেকনিক্যাল কাজ সম্পন্ন করার জন্য এটি অত্যন্ত কার্যকর।

---

### ২. টাইপিং অভ্যাসের সুবিধা: স্মার্ট কোটেশন (`“”`)
ডাবল কোটেশনের ক্ষেত্রে দুটি আলাদা শর্টকাট সেট রাখা হয়েছে যাতে ব্যবহারকারীর টাইপিং অভ্যাসে কোনো ব্যাঘাত না ঘটে:
1. **ম্যাক সিস্টেম অভ্যাস (`Option + 9` এবং `Option + 0`):** ম্যাকওএস ডিফল্ট শর্টকাটে যারা অভ্যস্ত, তারা খুব সহজেই ব্র্যাকেটের উপরের ৯ ও ০ কী দিয়ে এটি টাইপ করতে পারবেন।
2. **ভিজ্যুয়াল অভ্যাস (`Shift + Option + <` এবং `Shift + Option + >`):** তীরের দিক দেখে যারা বাঁকা কোটেশন বুঝতে পছন্দ করেন, তারা `<` ও `>` সমন্বিত কি-গুলো ব্যবহার করতে পারবেন।

## 🛠 ইনস্টলেশন ও কনফিগারেশন
ম্যাকওএসে ফাইলটি রুট সিস্টেমে প্রয়োগ করতে এবং পুরোনো ক্যাশ মেমোরি পরিষ্কার করতে নিচের ধাপগুলো অনুসরণ করুন:

### ১. ফাইল স্থানান্তরিত করুন

টার্মিনাল (Terminal) খুলে ফাইলটি সিস্টেমে কপি করুন:

```
sudo cp ~/Desktop/keyboards/UniJoy.keylayout "/Library/Keyboard Layouts/"

```

### ২. ফাইল পারমিশন সেট করুন

```
sudo chown root:wheel "/Library/Keyboard Layouts/UniJoy.keylayout"
sudo chmod 644 "/Library/Keyboard Layouts/UniJoy.keylayout"

```

### ৩. সিস্টেম ক্যাশ পরিষ্কার করুন

```
sudo rm -f /System/Library/Caches/com.apple.IntlDataCache*
rm -f ~/Library/Caches/com.apple.IntlDataCache*

killall TextInputMenuAgent 2>/dev/null || killall TextInputSwitcher 2>/dev/null
killall SystemUIServer

```

### ৪. রিস্টার্ট ও লেআউট সচলকরণ

1. আপনার ম্যাকটি **Restart** করুন। অথবা, লগ আউট করে আবার লগ-ইন করুন।

2. **System Settings** > **Keyboard** > **Text Input (Edit...)**-এ যান।

3. **+** বাটন চেপে **Others** ক্যাটাগরি থেকে **UniJoy** বেছে নিয়ে যুক্ত করুন।
